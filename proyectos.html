PROYECTO DESTACADO · EN LÍNEA

Portal ACIEM Norte de Santander

Portal institucional y Observatorio de Ingeniería y Desarrollo Regional.

  • Objetivo: presencia institucional, información de interés técnico regional e indicadores económicos actualizados automáticamente.
  • Tecnologías: HTML5 · CSS3 · JavaScript · Python · PHP · JSON · GitHub Actions · Cloudflare Workers · IA generativa.
  • Automatizaciones: actualización diaria de indicadores (TRM, petróleo Brent, carbón) mediante GitHub Actions; contador de visitas en PHP.
  • Indicadores dinámicos y asistente virtual en español integrado al portal, junto con acceso directo por WhatsApp.
  • Resultado: portal en producción, verificado en dispositivos móviles y con certificado SSL en línea.

CASO DE ESTUDIO

Situación inicial

El Capítulo Norte de Santander de ACIEM necesitaba una presencia web institucional: información de la organización, formación, eventos y datos confiables de indicadores regionales.

Problema

Datos económicos dispersos, actualización manual y costosa, y una web sin presencia móvil adecuada ni asistencia al visitante.

Solución desarrollada

Un portal institucional completo con observatorio de indicadores actualizados mediante automatización, versionado en GitHub, asistente virtual con IA en español y acceso directo por WhatsApp.

Tecnología y metodología

HTML/CSS/JavaScript en el frontend; Python y PHP para automatización y contadores; GitHub Actions para la actualización de datos; y Cloudflare Workers para el asistente de IA.

Resultado

Portal en producción, respaldado en GitHub, operativo en móviles y con certificado SSL activo. Un producto real que evidencia capacidad técnica de punta a punta.
